# PatternForge PRO V2 — Image & Pattern Generator Studio

![PatternForge PRO V2](https://img.shields.io/badge/PatternForge-PRO%20V2-6366f1?style=for-the-badge&logo=canvas&logoColor=white)
![Patterns](https://img.shields.io/badge/Patterns-203%20Procedural-10b981?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

A powerful, high-performance HTML5 Canvas 2D generative pattern and texture studio featuring **203 procedural & mathematical patterns**, **Easy Mode (✨ সহজ মোড)**, **One-Page Studio Dock**, real-time color harmony generator, print-ready resolution presets (8K / 4K / UHD / 300 PPI), batch generation, and direct multi-format export (PNG, JPG, WebP).

---

## ✨ Key Highlights

### 1. ✨ সহজ মোড (Easy Mode)
- **1-Click Magic Auto-Design**: Instantly generate balanced, publication-grade patterns with curated palettes and optimal scales.
- **8 Pre-designed 1-Click Themes**:
  - ⚡ **Cyberpunk Neon** (Vibrant electric pink, cyan, and violet spirals)
  - 👑 **Royal Gold** (Luxury metallic gold, champagne, and obsidian black)
  - 🌸 **Pastel Dream** (Gentle floral blush, mint, and lavender curves)
  - 🌌 **Cosmic Galaxy** (Deep space nebula and vortex fields)
  - 🍃 **Emerald Zen** (Emerald, jade, and bamboo torus knots)
  - 🌅 **Sunset Glow** (Radiant horizon orange, magenta, and twilight violet)
  - 🔯 **Sacred Neon** (Metatron's cube & Sri Yantra glowing lines)
  - ⚪ **Clean Minimal** (Sleek monochrome hyper-spirals)
- **Simple 4 Essential Controls**:
  - 📏 **Size / Scale (আকার)**
  - 🌀 **Angle / Rotation (ঘূর্ণন কোণ)**
  - 🧬 **Detail & Lines (রেখার ঘনত্ব)**
  - 🌈 **Color Blend (রঙের মিশ্রণ)**
- **Direct 1-Click Download**: Save high-resolution PNGs without sub-menu friction.

### 2. 🌀 203 Procedural & Mathematical Patterns
- **Spirals & Vortices (25)**: Archimedean, Logarithmic, Golden Spiral (Phi), Fermat, Hyperbolic, Vortex Whirlpool, Nautilus Shell, etc.
- **Spirographs & Rose Curves (25)**: Hypotrochoid, Epitrochoid, Guilloche, Rose Curves (3–12 petals), Lissajous, Harmonograph, etc.
- **Sacred Geometry (25)**: Flower of Life, Seed of Life, Metatron's Cube, Sri Yantra, Torus Mandala, Fibonacci Phyllotaxis, Celtic Knots, etc.
- **Fractals & Physics (25)**: Mandelbrot, Julia Flame, Sierpinski, Barnsley Fern, Dragon Curve, Lorenz Attractor, Magnetic Fields, etc.
- **Architecture & Tessellation (25)**: Islamic Girih, Moroccan Zellige, Penrose Tiling, Voronoi, Delaunay, Houndstooth, Damask, Op-Art Tunnel, etc.
- **Digital & Sci-Fi (25)**: Cyber Matrix, HUD Circles, Radar Sweep, Neon City Grid, Synthwave Wireframe, Circuit Board, DNA Helix, etc.
- **Classic Styles (53)**: Plaids, Tartans, Stripes, Polka Dots, Chevrons, Waves, Mandalas, Florals, Textures, and Themed designs.

### 3. 🖥 One-Page Master Studio Dock
- **Tabbed Dock Navigation**: Switch between `✨ সহজ মোড`, `🎨 Patterns (203)`, `🌈 Colors`, `⚙ Sliders`, `✨ FX`, `📐 Size`, `📦 Export`, and `☰ All (Scroll)` in a single click.
- **Canvas Quick-Cycler Ribbon**: Directly flip through patterns with `[◀ Prev]` `[🌀 Name #/203]` `[Next ▶]` `[🎲 Rnd]`.
- **Quick Harmonies Strip**: 1-click color harmonies (Monochromatic, Analogous, Complementary, Triadic, Neon, Pastel, etc.).
- **Print & Stock Metadata**: Automated stock platform tagging (Adobe Stock, Shutterstock, Freepik, Etsy) and CSV export.

## ⌨ Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Quick Randomize Design |
| `[` or `ArrowLeft` | Previous Pattern |
| `]` or `ArrowRight` | Next Pattern |
| `G` | Generate Pattern |
| `R` | Randomize Colors & Seed |
| `V` | Create Variation |
| `F` | Save to Favorites |
| `B` | Open Batch Modal |
| `P` | Open Projects Modal |
| `Ctrl + S` | Download Pattern |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `?` | Toggle Hotkeys Helper |

## 🛠 Technology Stack

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/rafiqulislam11/Image-generate-apps.git

# Open the project
cd Image-generate-apps
# Open index.html in your default browser
start index.html  # On Windows
```
